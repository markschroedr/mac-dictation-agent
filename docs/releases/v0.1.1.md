# Mac Dictation Agent 0.1.1

Mac Dictation Agent is a local push-to-talk tool for Apple Silicon Macs.

Hold Control+Shift, speak, then release. The app transcribes the recording locally with Parakeet and pastes the text into the field that was already focused.

This release includes:

- Native push-to-talk and locked long-form dictation.
- Recent transcript recovery.
- Optional file, batch, and continuous transcription.
- Optional local and cloud clipboard text-to-speech.
- Bounded five-second streaming diarization for long recordings.
- Updated Python dependency locks without known published vulnerabilities.
- Credential lookup limited to the process environment and the dedicated `tts.env` file.

## Install

Download `Mac-Dictation-Agent-0.1.1-macOS-arm64.zip`.

Unzip it. Control-click **Install Mac Dictation Agent.command**, then choose **Open**. macOS will ask for Microphone and Accessibility access.

The core install needs no Homebrew, Python, or Xcode. The first dictation downloads a local model of about 460 MB and can take several minutes while Core ML prepares it.

The app is ad-hoc signed, but not notarized. See the README for optional tools and exact privacy behavior.

On an M4 MacBook Air, a 6.70-second test sentence took 0.53 seconds median across five warm local runs. The repository includes the benchmark script and method.
